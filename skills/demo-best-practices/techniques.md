# Interaction techniques seen in booth demos

Each row: what it is, an example of where it was seen (described generically), and when it fits. Effort: S = hours, M = a day, L = days.

| Technique | Seen as | Fits when | Effort |
|---|---|---|---|
| Path picker on the first screen | "What does your team want to improve first?" with three goal cards; an industry picker; business or technical personas | Always. The answer chooses the path | S |
| Chapter tabs and a step counter | 6–7 named chapters with progress bars; "5 / 19" | Tours longer than 2 minutes | S |
| Build-on-click scenes | "Click anywhere or press → to build · 2/6" | Dense screens a staffer narrates | M |
| Pulsing hotspots | "Tap a pulsing dot to see what each one is doing" on a parallel timeline | One screen holds several actors | M |
| Callout bubbles with Continue | Numbered blue callouts that track their target, hideable with Esc | Self-guided use, no audio | M |
| Attract screen | "Move your mouse to begin" over a branded background | The shared wall loop (screen-modes.md §6) | S |
| Booth loop with captions | Each slide's narration plays with a caption band; runs silent with no audio device | Kiosks with or without sound | M |
| URL boot modes | `?kiosk`, `?silent` start the loop on open | Use the shared link options instead (screen-modes.md §3) | S |
| Clean capture mode | One key hides chrome for recording | Making fallback videos; pick a key the shared map does not reserve | S |
| Live network map | A packet animates to the host each call reaches; hosts change colour | Agent or automation demos with several targets | L |
| Run counters | Tool calls, commands, time, "changes made: 0" | Safety or read-only claims | M |
| Evidence drawer | Overview / Fix / Evidence, raw output with the key line highlighted | Engineers who want to check | M |
| Expandable reasoning rows | "Expand any row to see exactly what the agent read" | AI agent demos | M |
| Incident clock | T+00:03 next to the timeline | Incident and recovery stories | S |
| Same data, two clients | Toggle between a terminal client and a console client | Only if both clients are real | L |
| Presenter notes overlay | One key shows the note for the current step | Rotating staff | S |
| Speed control | 1× / 2× / instant | Long recorded runs | S |
| 30-second primer | Three cards before the run: what it is, what feeds it, what's shown | Products that need one concept first | S |
| Honesty banner and "what is real" page | "Replay of real, read-only runs… wording is scripted", ILLUSTRATIVE badge per simulated item | Any demo mixing real and simulated content | S |
| Trade-off card | ▲▼ per pillar for one recommendation | Advice or recommendation products | M |

**Not seen in any of the five demos:** QR codes, touch gestures, personalised take-aways.

**Usually reject:** mock product UI presented as the product; narration that needs speakers; before/after time claims without two recorded runs; roadmap screens at a public booth.
